# books.daycasion.com

Static site for DayCasion Keepsakes on the web: owners read their finished books as a flipbook and manage private
share links; guests open a shared book at `/s/#<link>`. Built from `keepsakes-v2/web-reader` in the DayCasion
backend repository (`node build.mjs prod`). No book content is stored here; books stay private in DayCasion's storage.
